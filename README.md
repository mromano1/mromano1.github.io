# Project Management Lessons GitHub Pages Site

This folder is ready to upload to a GitHub Pages repository.

## Option 1: Use the repository root
1. Unzip this folder.
2. Copy all files and folders into your GitHub Pages repository.
3. Commit and push.
4. In GitHub, go to **Settings → Pages** and publish from the main branch/root.

## Option 2: Use a `/docs` folder
1. Rename this folder to `docs`.
2. Put it in your repository.
3. Commit and push.
4. In **Settings → Pages**, choose the main branch and `/docs`.

The site uses static HTML, CSS, JavaScript, and PNG slide images. No build step is required.
